# lib-api

Collection of crates implementing the application APIs.

- **lib-asyncapi** – helpers for generating AsyncAPI documentation.
- **lib-asyncapi-macro** – procedural macros for documenting WebSocket handlers.
- **lib-ws** – WebSocket server framework built on Actix.
- **lib-ws-macro** – macros used by `lib-ws` to reduce boilerplate.
- **lib-api-macro** – derive macros for HTTP and JSON-RPC endpoints.
