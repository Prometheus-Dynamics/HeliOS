# Self-calibration, steep views

`selfcal-tagless` with the first 25 s replaced by views of the tag block from steep angles
(about 40° from each side, from above and from below, always aimed at the tags), for a
self-calibration window that wants tilted views (Eidos: a tag tilted 30° or more). Then the
same tag-free stretch and the return to the tags. Uncalibrated (scenario.json).
