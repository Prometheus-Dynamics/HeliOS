# Self-calibration, still views

The selfcal scene's tag block seen from 8 fixed poses spanning the steep views (straight on,
about 40° from each side, from above and from below, oblique), each held still for 1 s with a
0.3 s move between, looped (10.4 s). With a still camera there is no motion blur or animation
interpolation within a hold, so posing a held frame's true corners under the true lens isolates
the scene geometry from the camera's motion. Uncalibrated (scenario.json).
