---
title: Power
description: Live power readings, per-source breakdown, and sparkline graphs.
---

Power peripherals expose device power readings (watts/volts/amps) when supported by the hardware.

## Viewer

The viewer panel includes:

- Status (Active or awaiting samples).
- Latest watts/volts/amps readings.
- Update timestamp and reported interval.
- A **Refresh** button for a one-shot fetch.

## Graphs

The config panel includes sparklines for:

- Watts
- Volts
- Amps

Options:

- Autoscale toggle
- Last N samples window
