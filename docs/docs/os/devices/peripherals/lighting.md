title: Lighting
description: LED ring control, animations, saved presets, and advanced device settings.
---

The Lighting peripheral modal controls the device LED ring when the hardware/firmware exposes it.

## Viewer

The viewer panel provides:

- A live UI preview of the ring.
- Quick actions to apply colors/frames.
- Controls for brightness and frequency (when applicable).

## Animations

Lighting supports multiple animation modes (examples):

- Frame (manual per-LED color)
- Custom (sequence builder)
- Chase / Pulse / Rainbow / Breathing variants

You can:

- Preview animations.
- Save animations by name.
- Play or delete saved animations.

## Settings And Advanced

Lighting configuration is tied into device settings (GPIO, LED count, protocol, color order, brightness, frequency).

An advanced modal exists for deeper troubleshooting and low-level configuration when needed.
