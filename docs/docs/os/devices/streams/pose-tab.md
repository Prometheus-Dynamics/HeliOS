---
title: Pose (Per Stream)
description: Edit stream extrinsics (translation + rotation) used by rig/localization features.
---

The **Pose** tab stores the camera pose (extrinsics) for the current stream. This is geometric metadata, not an image setting.

## What You Can Do

- View the rig layout and camera list.
- Edit translation (X/Y/Z) and rotation (roll/pitch/yaw).
- Switch units (meters/inches).
- Save the pose to the stream.
- Clear pose (when supported).

## Related

- Robot/camera layout is managed in **OS > Settings > Rig Layout**.
