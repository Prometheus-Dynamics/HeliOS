---
title: Sources
---

Localization sources are selected from compatible stream, peer, profile, or peripheral feeds.

## What you can do

- Browse compatible sources grouped by origin.
- Search and filter the source list.
- Select multiple sources for a profile or solver.
- Assign per-source weights.
- See whether a source is calibrated and whether it is already used by another profile.
- Review per-source status such as detections, tag size, graph timing, and recent errors.
