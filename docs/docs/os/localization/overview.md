Localization is the UI for selecting pose/tag sources and visualizing them in 3D.

It does not create data by itself. You still need at least one stream/pipeline producing pose and/or ArUco/tag detections for this page to show meaningful results.

## What you can do

- Select which streams/peers are used as localization sources.
- Choose what coordinate space to solve/view in, and what outputs to display.
- Visualize tag detections and pose outputs in the 3D viewer.
- Manage camera extrinsics (camera pose) used by the viewer and solver.
- Upload and select field maps for field-relative visualization.
