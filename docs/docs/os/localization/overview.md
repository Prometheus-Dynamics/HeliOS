Localization is the workspace for building localization profiles from stream outputs, peer feeds, and field maps.

It does not create data by itself. You still need streams, peers, or pipelines that produce detections / pose data.

## What you can do

- Create, rename, remove, export, and import localization profiles.
- Select which streams / peers / pipeline outputs are used as localization sources.
- Choose solver mode per profile and per solver.
- Weight sources and enable/disable them without editing the pipelines that feed them.
- Configure tag size, excluded tags, field origin, and field map selection.
- Apply temporal stabilization and runtime tuning values.
- Visualize detections, solves, and field-relative outputs in the 3D workspace.
