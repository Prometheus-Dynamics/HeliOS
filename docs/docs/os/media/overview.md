Media is the on-device file library.

It contains:

- Files you upload (models, maps, archives, update images, data files).
- Files captured/generated by the device (for example: images/videos produced by streams or tooling).

## What you can do

- Browse files stored on the device.
- Filter by type (Image, Video, AI model, Archive, Update image, Data file, Unknown).
- Filter by capture stream (when an asset has a source stream id).
- Search by file name.
- Upload files (button or drag-and-drop).
- Open an asset to preview it, download it, edit metadata, or delete it.
- Select images/videos and create a replay stream ("media stream") that shows up as a normal stream in **OS > Devices**.

## How Media relates to streams

- Some assets are associated with a stream id (captured content). Those can be filtered using "Filter by stream".
- Manually uploaded files usually do not have a stream id and will show up under "All streams".

If you want to run pipelines on recorded media, use **Replay Streams**.
