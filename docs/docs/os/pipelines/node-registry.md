---
title: Node Registry
---

Node Registry lists the node types available on this device.

Nodes can come from the base image and from installed plugins.

## What you can do

- Browse and search nodes.
- Filter by tag, category, provider, and group.
- Change sort and view mode.
- Add a node to the current graph.

## How you use it in the Graph editor

1. Open **OS > Pipelines > Graph** and select a pipeline.
2. Click **Node registry** (bottom-left button).
3. Search/filter until you find the node you want.
4. Add it to the graph, then connect it to other nodes using ports.

You can also open the graph context menu and choose **Add node**.

## Notes

- The editor can still be used when the registry is unavailable, but port types may show as Generic.
- If the registry is empty or errors, check API connectivity (see **OS > Settings > API Endpoint**) and reload.
