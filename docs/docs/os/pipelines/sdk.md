---
title: SDK
---

The `SDK` tab embeds an IDE (OpenVSCode) in the Web UI when it is enabled in the image/preset.

This is optional. Most teams using premade images will not need it unless they are developing custom nodes/plugins.

## What you can do

- Open the embedded IDE workspace.
- Create a new plugin project (Node SDK plugin).
- Open an existing plugin project from the left sidebar (SDK tab).

## Notes

- If the IDE is not enabled, the SDK tab shows a message instead of an iframe.
- Plugin development is an advanced workflow and is not required for normal on-device use (streams, ArUco, tuning).
