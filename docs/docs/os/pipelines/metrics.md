---
title: Runtime Metrics
---

Runtime Metrics are shown in the `Tune` tab when streams are running and reporting metrics.

## What you can do

- See per-stream summaries (node count, average FPS, average ms).
- See the slowest node and recent errors (when reported).
- Use the status badge (Live/Offline) and "Updated" timestamp to confirm whether metrics are current.
- Refresh metrics while editing without leaving the current pipeline.

## Notes

- If no metrics are reported yet, start a stream (a live capture session) and check again.
- Metrics in the `Graph` workspace can also drive the heatmap overlay when available.
