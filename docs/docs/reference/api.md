The API pages are written by hand from the code; helios-api serves no OpenAPI or AsyncAPI
document.

- **HTTP API**: see [HTTP API](/api/http) (`backend/src/helios/api/src/routes/mod.rs` lists every route)
- **WebSocket API**: see [WebSocket API](/api/websockets)
- **NetworkTables (NT4)**: see [NetworkTables](/api/networktables)

## Versioning

The API prefix is `/v1`; breaking changes get a new prefix.
