## Finding Your Version (VERSION_ID / BUILD_ID)

In the Web UI, open **Settings** and read:

- `VERSION_ID`: the release version (for example `v2026.0.0`)
- `BUILD_ID`: the revision id for that build (useful when multiple builds exist for one version)
